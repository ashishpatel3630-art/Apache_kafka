# what is Apache Kafka (Kafka) ??

Apache Kafka is a open-source distributed messaging and event-streaming platform designed to handle large volumes of data reliably and efficiently between different applications and systems . 

# In Easy way we can say that Kafka is a system that allows different applications / services to send ,  store , and consume messages/ events without being directly dependent on each other . 

--------------------------------------------------------------------------------

# kafka is offically developed by LINKEDIN and later donated to Apache foundation 

# Kafka is open source

# Kafka is used by many large company like : linkedin , Airbnb , Netflix , uber , swiggy 

Kafka is commonly used for event-driven architectures, real-time data pipelines, log aggregation, stream processing, and communication between distributed services. 

--------------------------------------------------------------------------------

# What is message streaming 

Message streaming is a process in which message or event are continuously generated by producers on a streaming platform  and consumed by one or more consumers in near real-time

# in hindi 
Jab data/messages continuously generate hote hain aur bina wait kiye consumers ko process karne ke liye milte rehte hain, usse message streaming kehte hain.

# Zomato example
Delivery partner ki location continuously update hoti hai ->
Location Service Kafka mein events stream karti hai ->
Zomato app un events ko consume karke map par rider ki live location update karta hai.
