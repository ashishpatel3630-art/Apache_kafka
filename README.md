# Apache Kafka — Learn, Build & Contribute

A community-driven repository by Ashish to learn Apache Kafka from fundamentals to advanced concepts through notes, examples, hands-on code, system-design patterns, and open-source contributions.

# About This Repository
This repository is created for developers who want to learn Apache Kafka by understanding how it actually works and building things with it.

The goal is to make Kafka easier to understand while creating a place where developers can learn, experiment, contribute, and improve the project together.
